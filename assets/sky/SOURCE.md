# Photographic skybox

Kloofendal 48d Partly Cloudy (Pure Sky), Poly Haven, HDRI 4K.
Source: https://polyhaven.com/a/kloofendal_48d_partly_cloudy_puresky
License: CC0 — https://polyhaven.com/license
Download: https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/4k/kloofendal_48d_partly_cloudy_puresky_4k.hdr
Verified against the object server SHA-1: 49ccf5d052452294b48baa8a9888671d5cd1cf5b.

The sky shader aligns the photographed sun to the existing 68-degree solar
direction, using a smooth latitude remapping that leaves the horizon and zenith
fixed. It does not add a second sun. The image itself is unmodified.
Used for the background sky and water reflections. The city’s solar depth
textures, sun direction and diffuse lighting have not been recalculated.
